🚚 TCP vs UDP T37.01

TCP · proto 6

connection first, acked, ordered, 20-byte header
SYN ➜
⬅ SYN-ACK
ACK ➜ · data · FIN
closed port → RST ConnectionRefusedError

UDP · proto 17

no setup, no ack, no order, 8-byte header
datagram ➜
(nothing back)
closed port → silence, recvfrom() times out
!Trap: UDP sendto() to a closed port raises nothing. The app must time out and retry

📖DNST37.03UDP/TCP 53
Names ↔ addresses. Client asks the resolver (recursive); resolver walks root → TLD → authoritative (iterative), caches for the TTL.
1A name→IPv4 · AAAA name→IPv6 2CNAME alias→name · MX mail, lowest pref wins 3PTR IP→name dig -x 10.10.20.48 4no such name → NXDOMAIN
!Trap: PTR name is reversed: 48.20.10.10.in-addr.arpa
🔀NAT / PATT37.03router function
Rewrites private (RFC 1918) to public. PAT = many hosts, one IP, told apart by source port.
10.10.20.10:51000→203.0.113.5:51000
1inside local = private · inside global = public 2static 1:1 · dynamic pool · PAT overload 3ip nat inside source list 1 interface GigabitEthernet0/0 overload
!Trap: PAT = NAT overload; static NAT to publish a server
📈SNMPT37.03UDP 161 / 162
Manager (NMS) polls the agent's MIB; each object named by an OID, e.g. 1.3.6.1.2.1.1.5.0.
NMS— Get/Set → :161 —agent— Trap/Inform → :162
1Trap = no ack · Inform = acked 2v1/v2c community = cleartext 3v3 authPriv = auth + encryption
!Trap: authNoPriv is not encrypted; only v3 authPriv is
⏱️NTPT37.03UDP 123
One clock for logs, SNMP timestamps and certificates.
0 GPS→1→2→3⇢16 unsynced
1stratum = hops from the reference clock 2client ntp server 10.10.20.1 3verify show ntp status 4lab: stratum=2 refid=10.10.20.1
!Trap: lower stratum = closer to the source; 16 = unsynchronised
