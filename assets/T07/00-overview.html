T07.07
 scheme://host:port/path?query
REST = an architectural style over HTTP. Everything is a resource with a URI. Request = method + URI + headers + body. Response = status line + headers + body.
start/status lineheadersbody
REQUEST
POST /api/v1/devices HTTP/1.1 Authorization: Bearer tok-admin-7f3a Content-Type: application/json Accept: application/json {"hostname": "edge3", ...}
⇄
RESPONSE
HTTP/1.1 201 Created Location: /api/v1/devices/4 Content-Type: application/json {"id": 4, "hostname": "edge3", ...}
1path param = which resource/devices/1
2query param = filter / page?role=edge
!Trap: "where is it?" → code in the status line; Location Retry-After ETag in headers; data + error message in the body

RULES
T07.02
 6 constraints
Exam matches a description to the constraint name. Stateless and cacheable are the ones you see in code.
1Client-server: UI and data separate
4Uniform interface: same methods, URIs, self-describing msgs
2Stateless: token on every callAuthorization: Bearer …
5Layered: proxy / LB can sit between
3Cacheable: ETag → If-None-Match → 304
6Code on demand: the only optional one
!Trap: stateless = server keeps no client session, not "stores no data"

METHODS
T07.03 · T07.04
 POST · GET · PUT · PATCH · DELETE
Map to CRUD. POST targets the collection; PUT / PATCH / DELETE target one item. Safe = read-only. Idempotent = repeat gives the same end state.
1Create: server picks the idPOST /devices → 201 + Location
4DeleteDELETE /devices/4 → 204
2ReadGET /devices/1 → 200
5safe: GET HEAD OPTIONSidempotent: those + PUT DELETE
3Update: PUT = all fields, PATCH = somePATCH {"role": "core"}
!Trap: POST is neither (repeat = duplicate). DELETE twice → 204 then 404, still idempotent

CODES
T07.08 · T07.09
 HTTP/1.1 201 Created
Read the first digit first. 1xx = informational, interim (rare in APIs). 4xx = you fix the request; 5xx = the server failed.

2xx ✅ success

200 OK
201 Created
202 Accepted (queued)
204 No Content

3xx ↪️ go elsewhere

301 Moved Perm.
302 Found (temp)
304 Not Modified

4xx 🔧 client

400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
405 Method Not Allowed
409 Conflict
415 Unsupp. Media Type
429 Too Many Requests

5xx 🖥️ server

500 Internal Error
501 Not Implemented
502 Bad Gateway
503 Unavailable
504 Gateway Timeout
!Trap: 202 ≠ done (poll the Location job) · 204 / 304 have no body · 502 bad reply vs 504 no reply from upstream

4status line + headers-i / --include
2Basic auth · skip TLS check-u user:pass · -k
