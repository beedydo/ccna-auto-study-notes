Lab: POST /ctrl/api/v1/intents → 202 Accepted + taskId, then GET the task → SUCCESS. 2 calls (vs 8 at device level); the controller did 5 southbound PATCHes.
Trap: an app calling Catalyst Center's REST API uses the northbound API. Southbound = controller → device (NETCONF, OpenFlow, OpFlex, CLI, SNMP).
Each controller holds inventory, topology, policy and intent for its domain. 202 ≠ done: writes run as tasks; poll the task ID. Cost: you depend on the controller and on what its API exposes.
