Why automate

T12.01
manual CLI ✗ scale
  • 1Scale: 3 or 3,000 boxes, same effort
  • 2Speed: seconds, not a change night
  • 3Fewer errors, consistency: code types the config
  • 4Repeatable / idempotent: 2nd run → HTTP calls made by the script: 3, no PATCH
  • 5Compliance + audit: config in Git, every run logged
!Trap: automation needs an API + structured data + tooling; speed alone isn't the answer to "why".
