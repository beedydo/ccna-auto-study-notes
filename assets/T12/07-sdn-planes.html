Classic SDN used OpenFlow to write flow tables directly. Cisco controllers are hybrids: devices still run routing protocols; the controller owns policy and config.
Trap: SDN centralises the control plane, not the data plane. If the controller goes down, existing forwarding continues.
Planes: data = moves packets (FIB, MAC table) · control = decides where they go · management = configures and monitors (SSH, SNMP, NETCONF, APIs).
