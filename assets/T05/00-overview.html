12File header T05.01

diff --git a/X b/X = which file · a/ old, b/ new. index old..new mode = blob hashes: ignore.

3Old vs new T05.01

--- / a/ / - = before · +++ / b/ / + = after. --- /dev/null = file created · +++ /dev/null = file deleted.

4Hunk header T05.02

@@ -4,15 +4,17 @@ vlan 10
old: 15 lines, from line 4 (4–18)
new: 17 lines, from line 4 (4–20)
Net = 17 − 15 = +2. Counts include context. No count = 1. Text after @@ = section label only.
