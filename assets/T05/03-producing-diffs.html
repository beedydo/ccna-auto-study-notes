📊 Summaries instead of full hunks T05.05 · T05.06

git diff --staged --stat
banner.cfg | 1 + legacy.txt | 1 - switch.cfg | 6 ++++-- 3 files changed, 5 insertions(+), 3 deletions(-)
git diff --staged --numstat (added · deleted · file)
1 0 banner.cfg 0 1 legacy.txt 4 2 switch.cfg
git diff --staged --name-status
A banner.cfg # Added D legacy.txt # Deleted M switch.cfg # Modified (R = renamed)
switch.cfg: 6 = 4 + 2. 2 new VLAN lines (2 +) + 2 modified lines, and each modified line counts as 1 insertion and 1 deletion (2 +, 2 -) → 4 +, 2 -.
