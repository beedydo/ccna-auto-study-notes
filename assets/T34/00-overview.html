INVENTORY
T34.01
 inventory.yml group_vars/ host_vars/
Who gets automated. Groups of hosts (INI or YAML). Per-group vars in group_vars/<group>.yml, per-host in host_vars/<host>.yml. Host beats group; lists are replaced, not merged.
1group → hostsios_switches: → sw1, sw2
4which CLI/API dialectansible_network_os: cisco.ios.ios
2real address vs inventory nameansible_host: 10.10.20.12
5how to connectansible_connection:
  ansible.netcommon.network_cli
3host var wins over group varsw2 vlans = 10, 99 (not 20)
!Trap: hosts: nxos_switches never touches sw1; --limit only narrows, never adds

PLAY
T34.02
 playbook → plays → tasks → module
Play = which hosts + how. Task = name + one module + args. Tasks run top to bottom, each on all hosts before the next. Indentation is the structure.
1play header- name: Baseline the IOS XE switches
  hosts: ios_switches
4SSH CLI · NETCONF :830network_cli · netconf
2skip the setup taskgather_facts: false
5REST/RESTCONF · control nodehttpapi · local
3play vars override group_varsansible_connection:
  ansible.netcommon.httpapi
!Trap: register: one level too far left → YAML parsing failed; two modules in one task → conflicting action statements

MODULES
T34.03
 collection.namespace.module
The verb of each task. Network modules run on the control node and talk to the device over the connection. *_command = read (show), *_config = write.
1run show commands (read)cisco.ios.ios_command:
  commands: - show vlan brief
4NETCONF / RESTCONFnetconf_get netconf_config
restconf_get restconf_config
2push config lines (write)parents: "vlan {{ item.id }}"
lines: - "name {{ item.name }}"
5Jinja2 → file · printansible.builtin.template · debug
3any REST APIansible.builtin.uri: method: GET
!Trap: ios_command never changes config; ios_config alone doesn't save → save_when: modified

VARIABLES
T34.04
 {{ var }} · register · facts
Jinja2 fills {{ }} at run time. register saves a task's result dict. Facts = data read from the target (ansible_facts, ansible_net_*). -e always wins.
1substitutionhostname {{ device_hostname }}
4network factsansible_net_version from ios_facts
2save outputregister: vlan_out
5whole value is a var → quoteloop: "{{ vlans }}"
3read it back: a list, one per commandvlan_out.stdout[0]
!Trap: gather_facts: false on a play that prints ansible_facts → undefined variable

CONTROL
T34.05
 loop · when · notify → handlers
loop repeats a task per item (item). when is a raw Jinja2 test, no {{ }}, checked per item. Handler runs once, at the end, only if a notifying task was changed.
1repeat per VLANloop: "{{ vlans }}"
4queue the handlernotify: Save running config
2skip VLANs already therewhen: item.name not in vlan_out.stdout[0]
52 notifies → still 1 runRUNNING HANDLER [Announce rebuild]
3only lab switcheswhen: site_role == "lab"
!Trap: rerun with no change → handler not run; a later failed task → queued handler not run

RUNNING
T34.06
 ansible-playbook -i inventory.yml site.yml
Recap per host: ok (no change) · changed · skipped (when false) · failed · unreachable. Second run of an idempotent play = changed=0.
1dry run + show diff--check --diff
4read without running--syntax-check · --list-tasks
2one host only--limit sw2
5run 1 vs run 2 of build.ymlchanged=2 → changed=0
3more output · only some tasks-v … -vvvv · --tags vlans
!Trap: --check changes nothing; --syntax-check doesn't contact devices; ok = "no change", not "passed"
