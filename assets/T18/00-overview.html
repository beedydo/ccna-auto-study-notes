🌳 Hierarchy: one ID per hop, always in this order T18.04 · T18.08

1Organization

GET /organizationscarry id → organizationId e.g. 549236
➜

2Network (= site)

GET /organizations/{organizationId}
/networkscarry id → networkId e.g. L_646829496481105433
➜

3Device (by serial)

GET /networks/{networkId}/devicescarry serial e.g. Q2HP-3WCD-7KZE → GET /devices/{serial}
➜

4Client

GET /networks/{networkId}/clientsor GET /devices/{serial}/clients
!Trap: each path needs the ID the previous reply gave you. Network ID in an org path → 404. Lists are bare arrays: resp.json()[0]["id"], not ["response"]
