KANBAN
T01.03
 Scrum = timeboxes · Kanban = flow
Two ways to run agile. Scrum: fixed sprints, 3 accountabilities, 5 events, 3 artifacts. Kanban: a board, WIP limits, pull, no sprints.
1Roles: Product Owner (orders backlog) · Scrum Master (coach) · Developers
2Artifacts: product backlog · sprint backlog · increment
3Events: sprint planning → Daily Scrum (stand-up, 15 min) → sprint review (demo to stakeholders) → retrospective (improve the process)
4Kanban:

task C
task D
Doing (WIP 2)
task A
task B
Done
task Z
!Trap: review = inspect the product; retrospective = inspect the team's process. Kanban has no sprints and no fixed roles
🏭
LEAN
T01.04
 maximise value · minimise waste
From the Toyota Production System. Adapted to software by Mary & Tom Poppendieck (7 principles). A philosophy, often run with Kanban.
1Principles: eliminate waste · amplify learning · decide as late as possible · deliver fast
2empower the team · build integrity (quality) in · see the whole
37 wastes: partially done work · extra features · relearning · hand-offs · task switching · delays · defects
4Tools: MVP (smallest thing that tests value) · value-stream mapping · small batches · limit WIP
!Trap: "decide as late as possible" = keep options open until you have facts, not procrastinate. "Gold-plating" / unused features = waste
