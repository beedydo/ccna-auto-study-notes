Tiers: each tier is its own subnet; the internal firewall allows only the next tier's port (rules 3, 4). A hacked web server can't reach the DB.
Trap: a drop gives the client a timeout; a reject (RST / ICMP) fails fast. An L3/L4 rule can't see SQLi: that's the WAF's job, and it needs the decrypted HTTP.
Stateful: the DB's reply to a permitted flow passes with no rule (state table). A new connection from the DB to the app is denied.
