3⚖️Load balancerT41.03

Which server?
1Clients hit one VIP; a pool (target group) is behind it = scale out
2Round robin · weighted (2:1:1) · least conn (long requests) · source-IP hash
3Health check GET /health → 200 = UP; DOWN leaves rotation. All down → 503
L4 (NLB): IP + port, TLS passes through
L7 (ALB): Host, path, cookie; terminates TLS
4TLS offload (cert on LB) · sticky Set-Cookie: T41_STICKY=app1
Trap: sticky = uneven load, and the session still dies with its server. Only L7 routes by path
