Push: changes land when you run it; drift stays until the next run. Network devices can't host agents, so network automation = agentless push.
Trap: agentless ≈ push and agent ≈ pull, but they are separate axes. Salt has agents (minions) yet pushes (ZeroMQ 4505/4506).
Pull: the agent fixes drift on every check-in, automatically. ansible-pull turns Ansible into pull mode.
