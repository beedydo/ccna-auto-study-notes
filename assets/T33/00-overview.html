T33.02 · T33.03
 declarative = WHAT · imperative = HOW
Declarative tools diff desired vs actual and change only the delta. Run twice → second run changes nothing.

🎯 Declarative

end state; tool works out steps · Terraform, NSO, Puppet, Salt states

📜 Imperative

ordered steps · shell scripts, Ansible task order, Chef recipe order

🔁 Idempotent

re-run = no change · demo: 0 changed, 2 ok

⚠️ Drift

real config ≠ code (manual CLI edit) · found by plan / agent run

🔧 Mutable

patch in place (switches, routers, pets)

📦 Immutable

replace with new image (containers, AMIs, cattle)
!Trap: Ansible is procedural in order but its modules are idempotent; "declarative" usually = Terraform / Puppet / NSO on the exam

PUSH vs
PULL
T33.04
 who opens the connection?
Push: the control node connects out when you run it. Pull: an agent on each node checks in on a timer.

➡️ Push · agentless

Ansible (SSH / NETCONF / HTTPS), Terraform (APIs), NSO (NEDs), Salt master → minions

⬅️ Pull · agent-based

Puppet agent → primary server 8140 every 30m; Chef Infra Client → Chef Infra Server
!Trap: routers/switches can't run a Puppet/Chef agent → network devices = agentless push. Salt has agents (minions) but pushes
