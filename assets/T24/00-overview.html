Every MO has a class + DN in one tree (like ACI): sys = hardware, org-root = logical. aaaLogin → outCookie, refresh before 600 s.
1login<aaaLogin inName="ucspe" inPassword="ucspe" /> → outCookie="1791635060/7f27..."
2by class = all of them<configResolveClass cookie="..." classId="computeBlade" />
3by DN = one object<configResolveDn cookie="..." dn="sys/chassis-1/blade-3" />
!Trap: cookie goes inside the XML; errors are HTTP 200 + errorCode="551" (login) / "552" (cookie) / "103" (exists). Unknown DN → empty <outConfig/>
