🧱What YANG is T14.01

YANG moduleschema: shape, types, rules
RFC 6020 / 7950
→
ProtocolNETCONF :830
RESTCONF :443 · gNMI
→
EncodingXML · JSON
Protobuf

Describes config + state data; contains no data. Data lives in device datastores and payloads. Tools: pyang, YANG Suite.

Same leaf, two encodings:

XML (NETCONF: module = namespace URI) <interface xmlns="urn:ietf:params:xml:ns:yang:ietf-interfaces"> <name>GigabitEthernet1</name><enabled>true</enabled> JSON (RESTCONF, RFC 7951: module = name prefix, list = array) {"ietf-interfaces:interface": [{"name": "GigabitEthernet1", "enabled": true}]}
Trap: YANG ≠ protocol ≠ encoding. "Runs over SSH :830" = NETCONF, not YANG.
