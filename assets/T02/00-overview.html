OOP
T02.06
 class IOSXE(Device):
Four principles. A child inherits and can override. If the child defines its own __init__, the parent's runs only through super().__init__().
1Encapsulation: hide state behind methods_token + is_connected()
3Polymorphism: same call, different behaviourfor d in devices: d.connect()
2Inheritance: reuse + extend parentsuper().__init__(hostname, mgmt_ip, port)
4Abstraction: simple interface, details hiddenmain() never sees ports or URLs
!Trap: forget super().__init__() → AttributeError: 'IOSXE' object has no attribute 'hostname' · no private keyword (_x convention, __x name-mangles)
