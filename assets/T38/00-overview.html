🧱COMPONENTST38.01

🔀
SwitchL2 · dst MAC
MAC table, VLANs, trunks 802.1Q. Changes nothing in the frame.
🧭
Router / L3 switchL3 · dst IP
Longest-prefix match, default 0.0.0.0/0. Is the gateway (router port or SVI Vlan10).
🛡️
FirewallL3–L4 · state
Zones inside / dmz / outside, rules per zone pair, stateful (reply allowed), implicit deny.
⚖️
Load balancerL4–L7 · VIP
Clients hit the VIP; health checks pick a healthy server; rewrites dst IP.
📶
AP + WLCwireless
AP = radio ↔ wire. Lightweight AP joins a WLC over CAPWAP UDP 5246 ctrl · 5247 data.
Cisco icons: router = round puck · switch = flat box with arrows · firewall = brick wall. Read the label too.
Trap: routers rewrite the MAC per hop, never the IP. Only NAT and the LB's VIP → server step change an IP.

🔌PHYSICAL vs LOGICALT38.02

Physical

boxes, cables, ports, racks, speeds
pc1 eth0 ↔ acc1 Gi1/0/5
acc1 Gi1/0/48 trunk
"which port / which switch?"

Logical

subnets, VLANs, IPs, gateways, routing
VLAN 10 = 10.10.10.0/24
gw dist1 Vlan10
"which subnet / gw / path?"
Segment = VLAN = subnet: count L3 interfaces, not switches. /30 = transit link (2 hosts).
Trap: IPs + VLANs, no ports → logical. Two VLANs on one switch still need the gateway.

🏗️COMMON DESIGNST38.03

🏢 Three-tier campus

Core: fast L3, no policy
Distribution: SVIs = gw, ACLs
Access: ports, VLANs, PoE
Two-tier = collapsed core (core + dist merged)

🏭 Spine-leaf DC

spine1spine2
leaf1leaf2border
every leaf ↔ every spine · server→server = leaf→spine→leaf · ECMP, east-west

🛡️ DMZ

3rd firewall zone for public servers (web, mail, DNS). outside → DMZ on published ports only; DMZ → inside denied.

🌐 WAN / branch

branch router = branch gw + WAN edge. Transport: MPLS · Internet VPN · SD-WAN. Hub-and-spoke to HQ/DC.
Trap: no leaf–leaf or spine–spine links; servers plug into leaves only.

🎯EXAM: TRACE ANY PATHT38.04

1Same subnet? (apply the mask) → switch only, ARP for dst
2No → gateway = router / SVI / FW IP in the source's subnet
3Each L3 box: most specific route → next hop
4Firewall on path? zone pair + port matches a permit, else deny
5VIP? LB sends to a healthy server (none healthy → fails)
6Reply: state table lets it back; new reverse session still denied
Trap: frame leaving pc1 for a remote server: dst MAC = gateway, dst IP = server.
