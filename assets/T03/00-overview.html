A reusable, proven solution to a recurring design problem. Gives a shared vocabulary ("make it an Observer"). Gang of Four (GoF, 1994): 23 patterns in 3 groups.
1Creational: how objects are madeSingleton, Factory Method
3Behavioural: how objects talkObserver, Strategy
2Structural: how objects fit togetherAdapter, Decorator
4Architectural: whole-app layoutMVC (built from Observer + others)
!Trap: a pattern is a design idea, not a library you pip install · MVC is not one of the GoF 23

OBSERVER
T03.04 · T03.05
 attach() · detach() · notify()
One-to-many: the subject keeps a list of observers. On a state change it calls update() on each one automatically (push). Subscribe/unsubscribe at run time.
1subscribemodel.attach(syslog)
4Loose coupling: subject only knows update()
2broadcast on changeobserver.update(event)
5One change → many listeners, no polling
3unsubscribe at run timemodel.detach(alerts)
6Seen in: GUI events, model → views, webhooks, streaming telemetry
!Trap: observers do not poll · a detached observer gets nothing · same value again → no change → no notify
