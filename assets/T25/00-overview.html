Transactions

T25.03
One commit spans many devices: all succeed or none change (rollback).
POST service➜3 diffs➜xr0 fails➜all reverted
1preview, commit nothing
?dry-run=native · CLI commit dry-run outformat native
2undo file per commit
?rollback-id=true → {"rollback": {"id": 10002}}
3FASTMAP: service remembers what it created → change = re-run + diff, delete = reverse diff
no interface Loopback100 only on ios0 + xr0
!Trap: dry-run changes nothing (not CDB, not devices). FASTMAP = clean update/remove, not "fast".
🔄

Sync

T25.04
CDB is NSO's copy of each device. Someone edits a box by CLI → out-of-sync → NSO refuses commits to it.
🗄️ CDB
⬅ sync-from (device wins)
sync-to (NSO wins) ➜
⇄ check-sync / compare-config
🔧 ios0
1devices sync-from · devices device ios0 sync-to
2RESTCONF action = POST
.../tailf-ncs:devices/check-sync
3result "in-sync" / "out-of-sync"
!Trap: sync-from = pull from the device into NSO. sync-to = push NSO's copy to the device (overwrites the CLI change).
