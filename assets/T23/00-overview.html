🧱 FMC (Firepower Management Center)T23.01

Whatcentral manager for many Secure Firewall (FTD) devices: objects, access policies, deploy
AuthPOST /api/fmc_platform/v1/auth/generatetoken Basic → 204, tokens in headers
Calls/api/fmc_config/v1/domain/{DOMAIN_UUID} /object/hosts /policy/accesspolicies
SendX-auth-access-token: <token> · 30 min · 3 refreshes
!Trap: token is a header, not Bearer. A rule POST (201) changes nothing on the FTDs until deploymentrequests

🔥 FDM (on-box)T23.02

WhatFirepower Device Manager: web UI + REST API on one firewall, no FMC
Script→FDM on the FTD
AuthPOST /api/fdm/latest/fdm/token JSON "grant_type": "password"
SendAuthorization: Bearer<access_token>
!Trap: FDM = 1 box (OAuth-style token). FMC = many boxes (X-auth-access-token). Same FTD, never both

🪪 ISE (Identity Services Engine)T23.03

WhatAAA, network access control (802.1X/MAB), posture, guest, quarantine (ANC)
ERShttps://<ise>:9060/ers/config/networkdevice Basic auth on every call · Accept: application/json
MorepxGrid :8910 shares context (pub/sub) · OpenAPI /api/v1/ on 443
!Trap: ERS port 9060, off by default; user needs ERS Admin (RW) / ERS Operator (RO). pxGrid ≠ ERS

🧠 XDR T23.04

Whatextended detection & response: correlates endpoint, network, email, cloud telemetry
AuthPOST /iroh/oauth2/token client ID:secret + grant_type=client_credentials → Bearer, 600 s
Calls/iroh/iroh-inspect/inspect /iroh/iroh-enrich/observe/observables /iroh/iroh-response/respond/observables
!Trap: XDR orchestrates; the response runs in the integrated product (isolate = Secure Endpoint)

💻 Secure Endpoint (AMP)T23.05

Whatendpoint malware protection + EDR on laptops/servers
AuthBasic = client ID : API key · https://api.amp.cisco.com/v1/
CallsGET /v1/computers GET /v1/events PUT /v1/computers/{guid}/isolation
!Trap: isolation is PUT on the computer's connector GUID, not its hostname

🧪 Malware Analytics (TG)T23.06

Whatsandbox: detonates files/URLs, reports behaviours + threat score 0-100
Authapi_key parameter · https://panacea.threatgrid.com/api/v2/
CallsPOST /api/v2/samples /samples/{id}/state /samples/{id}/threat
!Trap: it analyses, never blocks. Async: poll state until succ

☁️ Secure Connect T23.07

WhatCisco SASE/SSE cloud on Umbrella + Meraki: remote access, DNS-layer + web security
Authkey + secret → POST https://api.umbrella.com/auth/v2/token → Bearer, 3600 s
Calls/policies/v2/destinationlists · Meraki: /organizations/{id}/secureConnect/sites
!Trap: the API key is not sent as Bearer itself: key + secret buy a token first
