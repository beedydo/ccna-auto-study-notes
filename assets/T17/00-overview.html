📡 Model-driven telemetry T17.05

Dial-in (dynamic)

collector connects + subscribes (gNMI, NETCONF). Gone when the session drops.

Dial-out (configured)

device connects to the receiver. Lives in running-config. receiver ip address

SNMP (old)

NMS polls (pull) every N min. MDT pushes periodic or on-change.
1"stream interface counters every 10 s" → MDT, not SNMP polling
2"device opens the TCP session" → dial-out
3"Nexus, reuse show commands, JSON back" → NX-API CLI /ins
4"Nexus, every interface object" → NX-API REST /api/class/l1PhysIf.json
!Trap: IOS XE update-policy periodic 6000 = 60 s (centiseconds); NX-OS sample-interval 10000 = 10 s (ms)
