🧮IPv4 SUBNETT36.01 · T36.05
network = IP AND mask
32 bits. /n = network bits, h = 32 − n host bits. Broadcast = all host bits 1. Usable = 2^h − 2. Block = 256 − mask octet.
192.168.5 + bits 10 → 26 network bits

🌐IPv6 (AWARENESS)T36.02
128 bits · /64 per LAN
8 groups of 4 hex digits. Drop leading zeros; :: replaces one run of zero groups. Link-local fe80::/10 on every interface.

🚪GATEWAY & ARPT36.03
dst AND my mask = my network?
Same network → ARP for the destination. Different → ARP for the default gateway. ARP = broadcast request, unicast reply, local subnet only.
pc1 10.1.10.50/24 · gw 10.1.10.1
10.1.10.77 → ARP dst
10.20.30.40 → ARP gw

Trap: the host never ARPs a remote IP; dst MAC = gateway, dst IP = server. Bad gw → local OK, remote fails
