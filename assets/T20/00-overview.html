Authentication

T20.03
Basic → Token → X-Auth-Token
  • 1POST /dna/system/api/v1/auth/token
    auth=HTTPBasicAuth(USER, PASSWORD)
  • 2reply {"Token": "eyJhbGci..."}, valid 60 min
    return resp.json()["Token"]
  • 3every other call: {"X-Auth-Token": token, ...}
  • 4missing / wrong header → 401 {"message": "Unauthorized"}
!Trap: X-Auth-Token, not Authorization: Bearer. Key is Token (capital T). Path is system, not intent.

Asynchronous tasks

T20.05
202 → poll /task/{taskId} → /file/{fileId}
1POST → 202→ 2{"taskId": ...}→ 3GET task: no endTime↻
4endTime set, isError false→ 5json.loads(task["progress"])["fileId"]
6GET /file/{fileId} → SUCCESS / FAILURE / BLOCKLISTED
In code: task = wait_for_task(token, task_id)
!Trap: 202 ≠ done, and a 200 task poll ≠ done. Finished = endTime. progress is a JSON string.
