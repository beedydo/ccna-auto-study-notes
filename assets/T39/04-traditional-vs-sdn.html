Trap: user packets never flow through Catalyst Center, APIC or the SD-WAN Controller. SDN moves the control plane; devices keep the data plane.
Northbound vs southbound: north = apps → controller (REST). South = controller → devices (OpenFlow, NETCONF, OpFlex, OMP). Don't swap them.
Not all "controllers" are equal: ACI fabric switches still run IS-IS / COOP / MP-BGP locally; Catalyst Center devices keep both control and data planes.
