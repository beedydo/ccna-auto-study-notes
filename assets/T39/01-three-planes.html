Trap: classify by the job, not the data. RESTCONF reading the RIB is still management. ARP and STP are control (they build tables), even though they're "Layer 2".
Transit traffic never touches the CPU. Traffic to the router's own IP (SSH, OSPF hellos) is punted to the CPU, and CoPP polices it.
Static route: typed in through management (CLI / NETCONF), lives in the RIB (control), forwards via the FIB (data).
management: config + telemetry control plane: protocol messages, table programming data plane: user packets
