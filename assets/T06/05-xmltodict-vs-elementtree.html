T06 · Two ways to read XML xmltodict vs ElementTree

T06.09 · T06.10
Same XML in, two very different objects out
Used by NETCONF (T15), AXL (T21), UCSM (T24), xAPI (T42)

📜 Input (one string)

X = """
<vlans xmlns="urn:example:vlans">
  <vlan id="10">USERS</vlan>
  <vlan id="20">VOICE</vlan>
</vlans>"""
1one root: vlans + default namespace
2vlan repeated → a list
3each has an attribute id and text
Pick: xmltodict when you want JSON-style ["key"] access. ElementTree when you want stdlib only, search by path, or namespaces handled exactly.

🧺 xmltodict.parse(X) → nested dict T06.09

{'vlans': {
    '@xmlns': 'urn:example:vlans',
    'vlan': [
        {'@id': '10', '#text': 'USERS'},
        {'@id': '20', '#text': 'VOICE'}]}}
Aattribute → '@id' · namespace decl → '@xmlns'
Battribute + text → text goes under '#text'
Ckeys are plain tag names (no {urn:…})
Devery value is a str: '10', not 10
d = xmltodict.parse(X)
for v in d["vlans"]["vlan"]:
    print(v["@id"], v["#text"])     # 10 USERS · 20 VOICE

🌳 ET.fromstring(X) → Element tree T06.10

root.tag     '{urn:example:vlans}vlans'
len(root)    2
root[0].tag  '{urn:example:vlans}vlan'
root[0].attrib  {'id': '10'}
root[0].text    'USERS'
Aattribute → .get("id") / .attrib dict
Btext → .text (str or None)
Ctag = {namespace-uri}name (Clark notation)
Dchildren: iterate, index, or search by path
ns = {"v": "urn:example:vlans"}
for v in root.findall("v:vlan", ns):
    print(v.get("id"), v.text)      # 10 USERS · 20 VOICE

❌ xmltodict: only ONE <vlan> comes back

xmltodict.parse(
  '<vlans><vlan id="10">USERS</vlan></vlans>')
{'vlans': {'vlan':
    {'@id': '10', '#text': 'USERS'}}}     # dict!
The loop now iterates the dict's keys: v["@id"] → TypeError: string indices must be integers, not 'str'. Works in the lab with 2 interfaces, breaks on the device with 1.

✅ Fix: force_list

xmltodict.parse(x,
                force_list=("vlan",))
{'vlans': {'vlan':
    [{'@id': '10', '#text': 'USERS'}]}}   # list
Name the tags that are YANG lists (interface, vlan, device). Or guard: if isinstance(v, dict): v = [v].

❌ ElementTree: namespace forgotten

root.find("vlan")              # None
root.findall("vlan")           # []
root.find("v:vlan", ns).text   # 'USERS'
root.find("{urn:example:vlans}vlan").text  # 'USERS'
No error, just None → next line .text raises AttributeError: 'NoneType'. NETCONF replies always have namespaces.
