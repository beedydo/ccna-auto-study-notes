Words that mean the same: serialise = encode = marshal = dump. Deserialise = decode = parse = unmarshal = load.
Trap · the s: loads/dumps = string. json.load("{…}") → 'str' object has no attribute 'read'.
Trap · YAML: yaml.load(text) with no Loader → TypeError (PyYAML 6). Untrusted input → safe_load.
Trap · ET: ET.parse() returns an ElementTree → add .getroot(). ET.fromstring() already returns the root.
Trap · bad JSON: json.JSONDecodeError (a ValueError). Bad XML: ET.ParseError. Bad YAML: yaml.YAMLError.
