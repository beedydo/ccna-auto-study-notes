🎛️ Three ways an API lets you pick

1Accept header (RESTCONF, ISE ERS) · 2Content-Type of the request (NX-API CLI) · 3URL suffix .json/.xml (APIC, NX-API REST). SOAP, NETCONF and UCSM: no choice, XML.

🧭 Read the wrapper first

Before indexing, print once: print(json.dumps(resp.json(), indent=2)). The wrapper (response, data, items, imdata, Results, none) decides your first key.
Trap: resp.json() on an XML reply raises requests.exceptions.JSONDecodeError. Check resp.headers["Content-Type"], then use ET.fromstring(resp.content) or xmltodict.parse(resp.text).
