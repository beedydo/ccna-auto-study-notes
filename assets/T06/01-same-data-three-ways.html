🐍 …and after xmltodict.parse (same XML)

{'interfaces': {
    '@xmlns': 'urn:ietf:params:xml:ns:yang:ietf-interfaces',
    'interface': [
        {'name': 'GigabitEthernet1', ..., 'enabled': 'true'},
        {'name': 'GigabitEthernet2', ..., 'enabled': 'false'}]}}

x['interfaces']['interface'][0]['name']   # no module prefix
Trap · XML: the namespace moves into an @xmlns key, so the root key is 'interfaces', not 'ietf-interfaces:interfaces'. And 'false' is a non-empty string, so if intf['enabled']: is always true.
Trap · JSON: RESTCONF puts the module prefix on the top key only (and wherever the model changes, RFC 7951). Forget it → KeyError: 'interfaces'.
Takeaway: JSON and YAML parse to the same Python object (YAML 1.2 ⊇ JSON). XML needs extra decisions: attributes, text-only values, one-vs-many lists.
