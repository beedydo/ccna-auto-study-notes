Edge = at/on the device. Fog = network-layer nodes (routers, switches, gateways) between edge and cloud.
Trap: edge doesn't remove the cloud. It cuts latency and WAN traffic; central analytics, storage and ML training stay central. Cisco edge platform = IOx, not IOS XE itself or Intersight.
Four benefits: lower latency · less WAN bandwidth · keeps working if the WAN fails · data stays local.
