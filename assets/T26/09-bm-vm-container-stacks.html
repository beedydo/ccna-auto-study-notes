Trap: "the container runs Ubuntu" means Ubuntu's libraries and shell, not its kernel. A Linux host can't run a Windows container; that needs a VM. (Docker Desktop on a Mac quietly runs a Linux VM.)

🎨 How to read the stacks

your app libraries / runtime OS with its 🧠 kernel hypervisor container runtime physical hardware
  • Read each column bottom to top: hardware → what manages it → what your app runs on.
  • Dashed boxes = one isolated guest. A VM box contains its own yellow OS; a container box doesn't.
  • Memory hook: each column shares more of the stack, so isolation goes down and density goes up.
  • The types stack: containers often run inside VMs in the cloud (EC2 + ECS/EKS).
