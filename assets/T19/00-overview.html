Networking side: VRF = L3 table, bridge domain = L2 domain, subnet = its gateway. App side: application profile holds EPGs. Contracts (subject → filter) allow EPG ↔ EPG.
EPG Frontend— consumes →contract web-to-app← provides —EPG Backend subject https → filter tcp-443

LOGIN
T19.04
 POST https://<apic>/api/aaaLogin.json
Body names the user. Reply carries the token in the body and as cookie APIC-cookie. Send the cookie on every call; refresh before 600 s idle.
1body{"aaaUser": {"attributes": {"name": USER, "pwd": PASSWORD}}}
2token path["imdata"][0]["aaaLogin"]["attributes"]["token"]
3keep session · logoutaaaRefresh.json · aaaLogout.json
!Trap: not Authorization: Bearer and not X-Auth-Token: it's a cookie. No cookie → 403; wrong password → 401; root key typo → 400

Know the DN → mo (one object). Know only the type → class (all of them). Every reply: {"totalCount": "n", "imdata": [...]}.
