📉 Network constraints → app symptom → fix T40.06 · 6.9

ConstraintWhat the app seesMitigation
Bandwidthbig payloads / backups slow, saturation → queueingcompress (gzip), paginate, filter fields, schedule bulk jobs
Latencyeach round trip costs RTT → chatty APIs crawl; timeoutsbatch calls, cache, fewer round trips, keep-alive session
Jittervariable delay → choppy voice / videoQoS (priority queue for voice), jitter buffer
LossTCP retransmits → slow; UDP media gaps; flaky timeoutsfix the link, QoS, retry with backoff
1lab, 40 ms per call: 20 x GET /devices/{id}: 0.92s vs 1 x GET /devices: 0.05s
2same body: identity 2349 B vs gzip 337 B
!Trap: more bandwidth does not fix a latency-bound chatty script; fewer round trips does
