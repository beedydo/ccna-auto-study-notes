T44.02 · T44.03
testbed: credentials: default: username: "%ENV{PYATS_USERNAME}" # env var, not a secret in git password: "%ENV{PYATS_PASSWORD}" devices: csr1: # must match the prompt hostname os: iosxe # picks Unicon plugin + Genie parsers type: router connections: cli: protocol: ssh ip: "%ENV{IOSXE_HOST}" port: 22
1from genie.testbed import load (or from pyats.topology import loader)
2testbed = load("testbed.yaml") · dev = testbed.devices["csr1"]
3dev.connect(log_stdout=False, learn_hostname=True)
CallReturns
dev.execute(cmd)str: raw CLI text, you regex it
dev.parse(cmd)dict: ["interface"]["GigabitEthernet3"]["status"]
dev.configure(CHANGE)wraps in config term … end
parse(cmd, output=text)parses saved text, no device
!Trap: execute() = string, parse() = dict. No os: → no Genie parsers. Device keys are case-sensitive: testbed.devices["CSR1"] → KeyError.
