T35.01
 48 bits = 12 hex = OUI + NIC
Burned-in L2 address of a NIC. First 24 bits = OUI (vendor, from IEEE). Lowest bit of octet 1 = I/G: 0 unicast, 1 group.

LOGIC
T35.02
 Switch.receive()
Every frame: learn the source, then look up the destination in the MAC table of that VLAN. Table = show mac address-table.

1 LEARN

src MAC → ingress port

2 FORWARD

known unicast → 1 port

3 FLOOD

bcast, mcast, unknown unicast

4 FILTER

dst on same port → drop

5 AGE

idle > 300 s → removed
1flood = every port in the VLAN except ingress
2change the timermac address-table aging-time 600
!Trap: the switch learns the source, never the destination. Unknown unicast is flooded, not dropped

VLANs
T35.03
 1 VLAN = 1 broadcast domain = 1 subnet
Splits one switch into separate L2 networks. A broadcast in VLAN 10 never reaches VLAN 20. MAC table is per VLAN.
