# Quizzes

Generated by `/quiz <topic|batch-N|dN|partner>` and `/crossstudy <beedy|bob>`. Questions come first in each file, and the answers are hidden in `<details>` blocks.

- All questions are original and written in exam style
- Log your scores in `data/practice-log.csv`, using one row per session per person.

## question-bank/

Third-party question bank, kept apart from the original questions above. `qa/` holds questions with answers, `dump/` holds questions only. See `question-bank/README.md`.
